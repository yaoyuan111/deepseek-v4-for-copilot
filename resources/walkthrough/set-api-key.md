Personal-AI for Copilot Chat uses your own API key (a DeepSeek API key or a compatible provider token) to make the Personal-AI model available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `Personal-AI: Set API Key`: Set or update your API key
- `Personal-AI: Clear API Key`: Remove your API key
- `Personal-AI: Get API Key`: Create a DeepSeek API key
